# 六项优先整改实施记录

日期：2026-10-22。起始基线：`1a123ec`。依据 `PROJECT_AUDIT_AND_PROGRESS_MASTER.md` 的风险排序实施，以下记录只覆盖本批六项，不代表整份审计清单已全部关闭。

## 1. 后端鉴权（A01）

- API、WebSocket、静态截图和 API 文档统一经过服务端认证，挂载到 URL 子路径时也不能绕过；`/health`、前端页面和前端构建资源保持可访问。私有响应禁止缓存。
- `POST /auth/status` 验证管理员凭据并签发随机 HttpOnly、SameSite=Strict Cookie；会话令牌不返回 JSON，也不存入 localStorage。
- `GET /auth/status` 恢复会话，`POST /auth/logout` 撤销服务端会话；过期、退出、修改凭据后无法重放旧令牌。WebSocket 在收到消息或推送前重新检查会话。
- 浏览器写请求、登录和 WebSocket 拒绝不受信任的 Origin；非浏览器客户端仍须先登录并携带会话 Cookie。
- 前端已接入会话恢复、退出和 WebSocket 延迟连接。旧 localStorage 登录标记会自动清除。

配置：`WEB_SESSION_TTL_SECONDS=28800`、`WEB_COOKIE_SECURE=false`、`WEB_ALLOWED_ORIGINS=`。HTTPS 部署应启用 Secure Cookie，并修改默认管理员密码。跨反向代理需要的 Origin 只能明确添加受信任地址，不能用通配符。

兼容说明：会话保存在当前服务进程内；服务重启后需重新登录。当前默认单 worker 启动方式可直接使用；部署多个 API worker 前需要共享会话存储。现有 API 自动化客户端需先调用登录接口并保留 Cookie。Live 测试已适配登录，本批未调用外部闲鱼或 AI 服务进行 live 验证。

## 2. 图片目录防越界（A02）

任务目录使用固定前缀和任务标识的 SHA-256 摘要，爬虫优先以 task ID 作为图片命名空间。下载与清理共用边界检查，只操作图片根目录下的直接子目录，拒绝符号链接或目录联接解析出的异常路径。任务名称中的 `../`、反斜线、绝对路径和 Unicode 不再成为路径组成部分。

旧版按任务名称生成的图片目录不会被自动删除，避免升级时误清理不可信历史路径。

## 3. AI 测试凭据保护（A09）

省略测试 Key 时，只允许使用已配置服务的协议、主机、端口与路径，以及已配置代理；自定义服务地址或代理必须显式提供测试 Key。地址拒绝非 HTTP(S)、用户信息、查询参数和 fragment。

出站客户端禁用重定向和隐式环境代理，避免凭据经跳转或环境代理转发；请求在工作线程中执行，连接完成后关闭传输客户端。测试失败仅返回错误类型，避免 SDK 异常回显密钥。用户显式提供 Key 时仍支持本机 HTTP 模型服务。

## 4. Windows 稳定性（A11、A12）

熔断器锁定独立的 `.lock` 文件，数据文件在关闭句柄后使用同目录临时文件原子替换；Windows 使用 `msvcrt` 锁，Unix 使用 `flock`，不再吞掉加锁失败。并发写入经过序列化，替换失败时保留旧状态。

移除 `ai_handler` 导入时对 `sys.stdout/sys.stderr` 的 `detach()`；pytest 捕获、StringIO 和无 stderr 场景保持原始流对象。

## 5. 任务身份与账号绑定（A03、A04、A13）

- `TaskUpdate` 仅规范化请求中出现的账号字段，启停和其他局部更新不会清空绑定账号。
- SQLite 的局部更新在同一写事务内读取、合并和保存，避免状态更新与账号编辑相互覆盖；已删除任务的迟到状态回写不会重建该任务。
- SQLite 在 `BEGIN IMMEDIATE` 事务中分配单调递增 ID，兼容已有零起始 ID，删除后不复用；更新使用 UPSERT，避免 REPLACE 的删除语义。
- Web/调度器启动子进程使用 `--task-id`，账号查找按 ID；CLI 保留唯一名称选择，但重名时拒绝执行并要求 ID。旧 JSON 未声明 ID 时采用列表位置，与旧配置迁移规则一致。
- 熔断记录按 task ID 隔离；首次遇到旧名称记录时复制已有暂停状态，后续同名任务不再互相影响。

无需手动迁移数据库：已有任务 ID 保留，ID 分配水位写入现有 `app_metadata` 表。

## 6. 风控停止与浏览器总量（A14、F04）

详情页的风控/登录异常向上抛出，不再落入通用容错后继续抓取。发现验证后立即取消后台分析，关闭详情页和浏览器，并在第一次风控失败时暂停任务；不再额外随机长睡眠后才退出。

`MAX_BROWSER_CONCURRENCY=2` 默认最多同时运行两个爬虫浏览器，可设置 1–32。Web、调度器及独立 CLI 通过数据库目录下的 OS 文件锁共享名额；等待名额可取消，进程被强制终止后 OS 自动释放锁。所有相关进程应使用相同的 `APP_DATABASE_FILE` 与并发配置，修改上限后重启相关进程。
