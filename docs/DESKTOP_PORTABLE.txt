闲鱼智能监控 · Goofish Monitor（Windows x64）

1. 双击 GoofishMonitor.exe 打开独立软件窗口。
2. 关闭窗口会缩到系统托盘，后台监控继续运行。
3. 单击托盘图标打开窗口；右键选择“退出并停止监控”彻底退出。
4. 默认登录账号为 admin/admin123；如已修改，使用自己的账号密码。
5. 账号、AI 和通知设置需在软件中配置，打包程序不包含个人账号或密钥。
6. 添加闲鱼账号时选择“扫码登录”，填写名称并生成二维码，使用闲鱼 APP 扫码确认。
   登录状态将自动保存；如二维码失效，可重新生成。也可以切换到“手动导入 JSON”。

默认数据与日志：
数据直接保存在 GoofishMonitor.exe 所在文件夹。
例如 EXE 位于 D:\GoofishMonitor\，则数据库为 D:\GoofishMonitor\data\app.sqlite3，
日志为 D:\GoofishMonitor\logs\desktop.log，界面缓存为 D:\GoofishMonitor\desktop-profile\。
请解压到可写的文件夹后运行；移动软件时应一起移动整个文件夹。
如显式设置了 GOOFISH_DATA_DIR 环境变量，则优先使用指定目录。
旧版 %LOCALAPPDATA%\GoofishMonitor 数据不会自动迁移或删除；需先从托盘退出旧版，
再将旧目录中的 .env、data、state、prompts 等所需文件复制到 EXE 所在文件夹。

若缺少桌面界面组件，请安装 Microsoft Edge WebView2 Evergreen Runtime：
https://developer.microsoft.com/microsoft-edge/webview2/

闲鱼抓取另需本机完整版 Microsoft Edge、Google Chrome 或 Playwright Chromium。
默认优先 Chrome；未安装时会自动尝试 Edge、Chromium，无需因换电脑修改配置。
WebView2 仅用于软件界面，不能代替抓取浏览器。便携 EXE 不内置上述抓取浏览器；
若日志提示全部缺失，请安装完整版 Edge 或 Chrome 后重新执行任务。
旧版本遇到 “Chromium distribution 'chrome' is not found” 时，可在 EXE 同目录
的 .env 中设置 LOGIN_IS_EDGE=true，退出托盘并重启软件（前提是本机已安装 Edge）。
浏览器缺失与闲鱼登录态无关；失败后的“临时图片目录不存在”表示还没有下载图片。
当前为未签名的便携版，
不包含自动更新或安装向导。升级前请从托盘退出旧版并保留数据目录。

若日志出现 LoginRequiredError 或 passport.goofish.com/mini_login.htm：
表示当前登录状态未通过闲鱼验证，任务会暂停，避免连续请求。
请在“账号管理”添加一个新名称并扫码登录，然后编辑任务，选择新登录的账号。
也可以在原账号的“编辑”中导入最新登录 JSON。新版本检测到原登录文件内容更新，
或任务改选其他账号后会解除旧暂停；无需删除任务、数据库或等待 24 小时。
若仍要求登录，请在普通浏览器确认该账号能正常打开闲鱼搜索页面并完成必要验证。
“未配置通知服务”只表示不会发送外部消息；暂停原因仍会显示在运行日志中。

build-info.json 记录本包来源提交、前端构建标识和构建时间，排查旧版本时请一并提供。
SHA256SUMS.txt 用于核对 EXE、本文和构建信息的完整性；PowerShell 可执行：
Get-FileHash .\GoofishMonitor.exe -Algorithm SHA256
