# 闲鱼智能监控零基础图文教程

面向没有使用过 AI 的读者，从打开软件、扫码添加闲鱼账号开始，学习关键词判断、AI 配置、任务创建、结果查看、定时监控、通知和常见问题排查。

- [阅读或打印 PDF](闲鱼智能监控零基础图文教程.pdf)
- [离线网页版](闲鱼智能监控零基础图文教程.html)

教程共 16 页，含 13 张当前界面的操作图、可复制的购买需求示例，以及每一步的完成标志。没有 AI 密钥时，可先按第 5 页使用关键词判断。

HTML 已内嵌全部图片，下载或复制这一份文件即可离线阅读，不需要单独携带 `images/` 文件夹；其中的软件和组件下载链接需要联网打开。浏览器打开后可使用顶部导航，也可打印或存为 PDF。

适用内容核对日期为 2026 年 10 月 24 日，以 Windows 桌面版中文界面为主；Web 版同名功能可参照。界面截图使用隔离的演示接口；账号、商品、价格、推荐理由和日志均为教学示例，没有连接真实闲鱼账号或 AI 服务。商品示意图不是真实商品照片。

`images/` 保留教程原始操作截图，方便后续更新。真实的默认数据位置和桌面运行行为见 [Windows 桌面版说明](../DESKTOP.md)。
